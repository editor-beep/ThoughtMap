# CODEX TICKET — INVESTIGATE TOUCH/TRACKPAD ZOOM DESYNC + NODE DISAPPEARANCE
## ISSUE SUMMARY
The graph behaves correctly when using:
- explicit zoom toggle buttons
- mode toggle buttons
BUT breaks when using:
- iPad pinch zoom
- Safari touch gestures
- Magic Keyboard trackpad pinch/scroll zoom
- touchpad gesture scaling
Symptoms:
- nodes disappear entirely
- card mode fails to engage
- dot/card thresholds fail
- minimap becomes desynced
- rendered node count still reports valid values
- zoom label updates but viewport/render state collapses
- sometimes graph only returns after refresh
This strongly suggests:
```txt
camera zoom state
≠
render mode state
≠
viewport transform state

There is likely:

* duplicate zoom authority
* invalid scale normalization
* NaN transform propagation
* gesture delta instability
* ReactFlow / viewport race condition
* stale derived render state
* broken threshold crossing logic
